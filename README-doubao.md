# 脑子推植物（草坪主题推箱子）

一个纯单机、无需服务器的微信小程序，采用卡通草坪主题：**脑子当玩家、植物当箱子、僵尸当目标点**，每过关弹出大字「脑子吃掉了你的僵尸」。进入后是**主菜单**，包含开始/继续游戏、选关、设置、关于；游戏内置 12 个由易到难的关卡，支持移动、推箱、撤销、重开、步数统计、滑动手势，以及自定义图片替换。

元素对应关系：玩家=脑子、箱子=植物、目标点=僵尸、箱子到位=植物对上僵尸（金色发光）、墙=树篱、地面=草地。

## 一、如何运行

1. 下载并安装「微信开发者工具」（微信公众平台官网可下）。
2. 打开开发者工具，选择「导入项目」，目录选择本文件夹 `sokoban-doubao`。
3. AppID 一栏：
   - 只是体验/测试：选择「测试号」或保持当前 `touristappid`；
   - 要发布：先在微信公众平台注册小程序，把你自己的 AppID 填进 `project.config.json` 的 `appid` 字段。
4. 导入后左侧模拟器即可直接游玩，也可点「预览」用手机扫码体验。

## 二、如何替换箱子、目标点等图片（重点）

每个元素都可以**单独替换**，不影响其他元素。

1. 准备正方形、透明底 PNG（建议 128×128 或 256×256）。
2. 按下列文件名命名，放入 `images/` 目录：

   | 文件名 | 对应元素（主题） |
   |---|---|
   | wall.png | 树篱（墙） |
   | floor.png | 草地（地面） |
   | target.png | 僵尸（目标点） |
   | box.png | 植物（箱子） |
   | box-on-target.png | 植物对上僵尸（箱子到位） |
   | player.png | 脑子（玩家） |

3. 打开 `utils/config.js`，把 `custom` 中对应元素改为 `true`。
   例如只替换箱子和目标点：

   ```js
   custom: {
     wall: false,
     floor: false,
     target: true,    // 已替换目标点
     box: true,       // 已替换箱子
     boxOnTarget: false,
     player: false
   }
   ```

4. 保存（Ctrl+S）后自动生效，无需改其他代码。
   说明：`box-on-target` 是箱子到位后的样子，若不单独提供，可复用 `box.png` 的设计。

## 三、如何添加 / 修改关卡

关卡数据在 `utils/levels.js`，使用标准 Sokoban 字符：

| 字符 | 含义 |
|---|---|
| `#` | 墙 |
| `.` | 目标点 |
| `$` | 箱子 |
| `*` | 箱子在目标点 |
| `@` | 玩家 |
| `+` | 玩家在目标点 |
| 空格 | 地面 |

在数组里新增一个 `{ name: '第 N 关', map: [ ... ] }` 即可；每一行字符串长度可以不同，程序会自动对齐。

## 四、关于成本、服务器与广告

- **成本**：个人主体注册小程序免费，不强制认证；纯单机零服务器开销。
- **服务器**：关卡与通关进度都存在本地，**不需要服务器**。
  以后若想做全网排行榜，可开通「微信云开发」，免费额度通常足够。
- **广告变现**：小程序累计独立访客（UV）超过 500、无违规后，可在公众平台开通「流量主」，接入激励视频/横幅广告。
  接入方式：在需要展示广告的页面调用 `wx.createRewardedVideoAd`（激励视频）或 `wx.createBannerAd`（横幅），并在公众平台获取广告位 ID。
  休闲小游戏一般按广告流水约 50% 分成，实际收益取决于用户量。

## 五、文件结构

```
sokoban-doubao/
├── app.js / app.json / app.wxss   小程序入口、全局数据与配置
├── project.config.json            开发者工具项目配置
├── sitemap.json
├── utils/
│   ├── levels.js                  12 个关卡数据
│   └── config.js                  图片替换开关与路径
├── pages/
│   ├── home/                      主菜单（开始/继续、选关、设置、关于）
│   ├── index/                     游戏页（移动/推箱/撤销/重开）
│   ├── levels/                    选关页（进度条、解锁网格）
│   ├── settings/                  设置页（音效、震动、清除进度）
│   └── about/                     关于页（介绍、玩法、图例）
├── images/                        放自定义图片（详见目录内说明）
├── sokoban-preview-doubao.html     浏览器可直接玩的完整预览（双击打开）
└── check-levels-doubao.js         关卡可解性自动验证脚本
```

**页面跳转关系**：主菜单 →（开始/继续）游戏；主菜单 → 选关 → 游戏；游戏内可随时返回主菜单、打开选关或进入下一关。

## 六、验证情况

- 12 个关卡均已通过自动求解器（BFS）验证可解。
- 完整预览版已实测：主菜单、选关、设置、关于、游戏各页面跳转正常；移动、推箱、箱子到位、步数、过关弹窗均正常。
- 运行方式：双击 `sokoban-preview-doubao.html` 即可在浏览器直接试玩（键盘方向键或屏幕按钮）。
